# Conversor de Monedas 💰

## Descripción 📄
Este es un conversor de monedas en **Java**, que permite calcular el valor de diferentes monedas usando la API de **ExchangeRate-API**. Su interfaz de línea de comandos presenta un menú interactivo para realizar conversiones entre **dólar, euro, peso chileno y peso argentino**.

## Características 🚀
- Conversión entre **USD, EUR, CLP, ARS**.
- Consulta en tiempo real de tasas de cambio desde la API.
- Manejo seguro de errores y validaciones.
- Interfaz de usuario en consola con formato mejorado.

https://v6.exchangerate-api.com/v6/215ff05f3318144acc182b6e/latest/USD

El programa extrae las tasas y las aplica correctamente según la conversión seleccionada.
